## What it does

`main.ts` (Node 22, standard library only, fully deterministic) writes one
single sentence of horror, under 200 characters, to `/output/entry.txt`.
The text is a constant — the same words every run, byte for byte — because
the scare has to live in the words themselves.

## The line

One breath, one sentence, one chill: a concrete image with a turn the
reader has not met a hundred times before, and a last word that lands
the blow. No mirror, no doll, no basement — the dread is earned, not
announced, and it outlasts the line.
